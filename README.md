## Deskripsi Proyek
Sistem ini dirancang untuk mengelola pemesanan dan reservasi meja serta kursi restoran, meminimalkan antrean di lokasi, serta memberikan kepastian ketersediaan tempat bagi pelanggan sebelum kedatangan.

---

## User Flow
Flow user: buat akun - pilih jadi pemiliki restoran atau pencari restoran - login:
- A. Sbg pencari:
Memilih rekomendasi di beranda (berdasarkan lokasi yg dicari) - user baca menu foto dan deskripsi (pemiliki harus kasih perkiraan slot kursi dan ketentuan reservasi) - user reservarsi (pesan jumlah kursi-kasih notes, dan durasi) - captcha - dapet kode booking dan nomor - user review
- B. Sbg pemilik:
Buat unit restor dengan deskripsi, kontak, dan ketentuan - pemiliki dapet notif jika ada reservasi - acc atau tolak (harus kasih notes) - nonaktifkan restoran dari beranda jika full
